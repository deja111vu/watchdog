## Простой сторожевой таймер (Watchdog) 
для отслеживания нормальной работы ПК.
Пригодится при необходимости получения уведомлений, если ПК завис или выключился.

<img src=https://github.com/deja111vu/watchdog/blob/main/screenshot-1.png>

Установка скрипта:

1. Скачайте все файлы на компьютер.

2. Создайте новый workflow в n8n, в правом верхнем углу нажмите "import from file", выберите "Watchdog_workflow.json"

3. Откройте двойным кликом ноду "Setup" и заполните поля: 
- delay - необходимо указать количество минут задержки проверки пингов от ПК. Должно составлять время периодичности пинга + 3 минуты (Стандартно пинг отправляется каждые 10 минут, поэтому в поле указано 13).
- Bot_token - Введите Токен бота Телеграм, который будет отправлять вам сообщение при отключении ПК.
- Telegram_Chat_ID - Введите ID чата с этим ботом.
- Error_message - имеет предустановленное сообщение об ошибке с указанием имени компьютера, который перестал пинговаться. Можно изменить на свое.

4. Запустите триггер "Click for setup and test", чтобы сконфигурировать стартовую временную метку таймера и проверить доступность бота Телеграм.

5.  Откройте двоным кликом ноду "Webhook", перейдите во вкладку "Production URL" и скопируйте адрес вебхука.

6. Активируйте workflow.

7. На вашем ПК правым кликом на "send_ping.vbs" откройте контекстное меню и выберите "Изменить". В поле шага 2 - strURL = "<SET_YOUR_WEBHOOK>" замените <SET_YOUR_WEBHOOK> на ранее скопированный адрес вебхука из n8n. Сохраните файл.

8. Запустите для установки задачи в Планировщике задач - "Autostart_setup.bat" 
Настройки: 
По умолчанию пинги отправляются каждые 10 минут.
Для изменения периода отправки пингов в шаге 3 необходимо изменить цифру в ключе "/mo 10" команды установки задачи "schtasks", а также скорректировать настройки ноды "Setup" в n8n.

9. Если необходимо остановить сторожевой таймер - Запустите для удаления задачи из Планировщика задач "Autostart_stop.bat".
